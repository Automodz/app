# reference/customer-old

The customer application as it stood at commit `37fc54f`, the last commit before
the customer UI was replaced.

**This folder is never imported and never executed.** It is excluded from
TypeScript, ESLint and the Next build. It exists so that every rebuilt screen can
be diffed against the behaviour it must preserve.

A file is deleted from here only when its row in `docs/UI-MIGRATION.md` reads
100%.
